Character portraits for the talk panel.

Name each file after the character, lower case, spaces as underscores, no apostrophes:
  Old Gus             -> old_gus.png
  The Crown's Herald  -> the_crowns_herald.png
  The Informant       -> the_informant.png
  The Silent Partner  -> the_silent_partner.png

Square images work best (the frame shows 160 x 160, so 512 x 512 is plenty).
Any character without a picture shows a coloured square with their initials instead.
